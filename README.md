# Secure Messenger (가칭)

모든 대화가 종단간 암호화되는 텔레그램 스타일 모바일 메신저입니다.

- 기반: Matrix 프로토콜 + FluffyChat(Flutter) 포크
- 핵심 기능: 위장 비밀번호 입력 시 지정한 대화방과 친구를 양쪽 기기에서 삭제
- 가입: 아이디만 사용 (전화번호 없음)
- 라이선스: AGPL-3.0 (FluffyChat 기반)

이 앱은 [FluffyChat](https://github.com/krille-chan/fluffychat) v2.11.5를 바탕으로 만들었습니다. 원본 소개는 [README-FluffyChat.md](README-FluffyChat.md)에 있습니다.
